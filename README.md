<summary><b>Run it, write a post, publish</b></summary>
<br>

You need Node.js 20.9 or newer and pnpm 10.

```bash
pnpm install
pnpm dev      # opens at http://localhost:3000
pnpm check    # lint, build, type check, links and SEO: run it before you push
```

**New post:** add a file such as `content/my-post.mdx`. The file name becomes the address. Start it with:

```md
---
title: "Your post title"
publishedAt: "2026-11-02"
summary: "One or two sentences, 70 to 165 characters."
---
```

Write the post below that, then commit the file and push to `main`.

Keep `public/google3419091e9a1248e3.html` and `public/_redirects`: they keep Google Search Console verified.
